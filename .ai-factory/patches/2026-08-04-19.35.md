# EPUB XHTML self-closing title extraction

**Date:** 2026-08-04 19:35
**Files:** pkg/epubimport/ranges.go, pkg/epubimport/inspect_test.go
**Severity:** high

## Problem

Selected EPUB chapters failed with `epub_extract_failed`, leaving the newly
created book without imported chapters.

## Root Cause

The source EPUB used valid XHTML `<title/>`. `golang.org/x/net/html` follows
HTML parsing rules, where a self-closing non-void `title` is not closed. It
therefore consumed the body as title text and the chapter fragment anchor was
unavailable.

## Solution

Normalize XHTML self-closing non-void tags to explicit open/close pairs before
the HTML DOM range parser runs. Void HTML elements retain their original form.
A regression fixture reproduces the source pattern.

## Prevention

- Treat EPUB content documents as XHTML as well as permissive HTML.
- Exercise self-closing non-void XHTML elements in extraction tests.
