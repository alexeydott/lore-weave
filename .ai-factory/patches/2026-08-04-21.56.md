# EPUB locale parity gaps

**Date:** 2026-08-04 21:56 MSK
**Files:** `frontend/src/i18n/locales/*/books.json`
**Severity:** low

## Problem

Sixteen supported book locales lacked every `epubImport` key, so the locale
parity gate reported the new EPUB V2 namespace as incomplete.

## Root Cause

The initial EPUB V2 UI provided translated English and Russian copy only, while
the repository parity gate compares every supported locale with the English
namespace.

## Solution

Added the complete English `epubImport` namespace as an explicit fallback to
the sixteen remaining book locale files. English and Russian remain translated;
the fallback does not claim native translations for the other locales.

## Prevention

- Add a new namespace to every registered locale in the same change.
- Run the namespace-scoped parity check before declaring a localized feature
  complete.
- Keep fallback copy explicit until a locale receives reviewed translation.
