# EPUB wizard lost durable controls

**Date:** 2026-08-04 21:31 MSK
**Files:** `frontend/src/features/epub-import/EpubImportWizard.tsx`
**Severity:** medium

## Problem

The EPUB wizard component regression suite failed before exercising its flow.
The file input, metadata policy and import options controls, replace-all
confirmation, persisted job restoration, report, Resume, and Rollback selectors
required by the UI contract were absent from the rendered component.

## Root Cause

The wizard retained the API payload defaults but a prior UI simplification had
removed the corresponding stateful controls and the local-storage restore path.
The component tests remained the only executable contract for those durable-job
behaviours, so the drift was exposed only when the focused suite was rerun.

## Solution

Restored explicit metadata-policy and import-option state, replace-all
confirmation, local-storage job persistence and restoration, and stable test
selectors. The start payload now reflects the selected controls rather than
fixed client defaults.

## Prevention

- Keep durable-job restoration and terminal actions in the wizard component
  suite whenever the UI is refactored.
- Run the focused EPUB wizard tests and browser smoke after changing the wizard.
- Treat API payload controls and their visible UI state as one contract.
